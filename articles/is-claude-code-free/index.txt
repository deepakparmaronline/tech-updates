Anthropic&#39;s current <a href="https://claude.com/pricing">pricing page</a> lists Claude Code as unavailable on Free and available on Pro and Max. Pro is listed at 20 US dollars per month when billed monthly, or 17 dollars per month with an annual subscription billed up front. Max starts at 100 dollars per month in the US. Prices, taxes, and offers can differ by region.</p>
<p>You can also use Claude Code through an API billing setup, but that is a different payment path. Installing the command line tool does not mean that all model usage is free. Before paying, confirm which account is signed in, which plan you have, and whether your terminal is using subscription access or API credentials.</p>
<h2 id="what-the-question-really-means">What the Question Really Means</h2><p>When people ask whether Claude Code is free, they may mean three different things. They may ask whether the program can be downloaded without paying, whether a free Claude account can use it, or whether every coding request is included in a subscription. Those are not the same question.</p>
<p>The important distinction is between installing the tool and paying for model usage. You can read the official setup instructions and install the command line client, but access to Claude models still depends on a supported plan or a configured billing route. Anthropic&#39;s <a href="https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan">Claude Code plan guide</a> explains how eligible subscriptions connect to the tool and what happens when usage limits are reached.</p>
<p>This matters because a terminal message about billing does not always mean that Claude Code itself requires a separate add on. It may mean that the current session is connected to a Console API key, the wrong account is active, or the plan allowance has been reached. Check the actual setup before changing subscriptions.</p>
<h2 id="how-it-works">How It Works</h2><p>Claude Code is a coding tool that can work with files and commands in a project. Its subscription access is tied to the eligible Claude account you use to authenticate. Anthropic&#39;s pricing page currently lists Claude Code on Pro and Max, while its support guide explains that subscription usage limits apply across Claude and Claude Code.</p>
<p>The allowance is not a promise of unlimited requests. A small question about one file may use less capacity than a large task that reads a repository, edits many files, runs repeated tests, and asks for several revisions. The size of the codebase, length of the context, model selected, and number of parallel sessions can affect how quickly you reach a limit.</p>
<p>API billing works differently. If you use a Console account or configure an API key, requests can be charged according to API usage rather than being covered by your Claude subscription allowance. Treat the two routes as separate until you have confirmed which one the current terminal session is using. Do not assume a subscription automatically pays for every API request.</p>
<h2 id="practical-steps">Practical Steps</h2><h3 id="1-check-the-current-plan-page">1. Check the current plan page</h3><p>Open <a href="https://claude.com/pricing">Claude pricing</a> and confirm the current comparison for Free, Pro, and Max. The page can change, and your local pricing may differ from the US prices shown here. Review the features that matter to you, not just the headline price.</p>
<p>If Claude Code is missing from the account&#39;s feature list, check that you are signed into the correct account and region. Do not rely on an old screenshot or a forum post that describes a previous pricing experiment. The live vendor page is the better starting point.</p>
<h3 id="2-confirm-how-claude-code-is-signed-in">2. Confirm how Claude Code is signed in</h3><p>Open Claude Code and check the account or authentication flow described in the official setup guide. If you used a Console API key earlier, the session may still be using that billing route. Anthropic&#39;s support guide explains that users can change the active account through the tool&#39;s login flow when needed.</p>
<p>Do not paste API keys, access tokens, or authentication output into a public issue. If you need help, share only a redacted error and the general type of account you are using.</p>
<h3 id="3-check-environment-variables">3. Check environment variables</h3><p>Developer environments sometimes define an API key for scripts or tools. If Claude Code is picking up an API key when you expected subscription access, the usage may follow the API billing route. Check your shell configuration and project environment without printing secrets into logs or chat.</p>
<p>If you are unsure, ask the official documentation how authentication works for your installation method. Do not delete every environment variable or credential file at random. Make one controlled change, restart the terminal, and verify which account is active.</p>
<h3 id="4-understand-the-limit-before-upgrading">4. Understand the limit before upgrading</h3><p>Anthropic says that eligible Pro and Max usage limits are shared between Claude and Claude Code. A long chat or a complex coding session can use capacity that you also need in the Claude app. If you reach a limit, the support guide describes options such as waiting for the allowance to refresh, using available usage credits, switching to an API billing path, or considering a higher plan.</p>
<p>Upgrade only if the extra capacity matches your work. A higher plan may be useful for larger repositories or frequent coding sessions, but it is not automatically the right choice for occasional edits. Try the smallest eligible plan on a real project before paying for more capacity.</p>
<h3 id="5-keep-subscription-and-api-costs-separate">5. Keep subscription and API costs separate</h3><p>Before running a long task, decide whether it should use subscription access or API billing. If your organization reimburses software, keep the receipt and billing account clear. If you work on a client project, confirm that the client permits the tool and that no private code or credentials are being sent to an unapproved service.</p>
<p>For API usage, check the official billing information and current rates. For subscription use, check the plan&#39;s current limits and account settings. These routes can have different controls, and a successful sign in does not prove that the request will be covered by the plan you intended.</p>
<h2 id="common-problems">Common Problems</h2><p>A common problem is signing in with a different account from the one that has the paid subscription. This can happen when a personal Claude account and a Console account are both used on the same machine. Check the active account before paying again.</p>
<p>Another issue is reaching a usage limit while using Claude in the web app and Claude Code together. The official guide says these activities can share an allowance on eligible plans. If a task uses a large repository or multiple sessions, it may consume capacity faster than a short coding prompt.</p>
<p>A credit balance error can also point to the API route. Check whether the current session uses subscription access or API billing, and confirm the balance and billing configuration for that route. Do not share a secret key with support or put it in a screenshot.</p>
<p>Finally, an old guide may list a different plan or limit. Subscription features can change. Use Anthropic&#39;s current pricing and support pages rather than relying on cached search snippets or old community posts.</p>
<h2 id="what-does-not-work">What Does Not Work</h2><p>Installing Claude Code again will not fix a billing account mismatch by itself. Reinstall only when there is a clear installation problem. First check the account, authentication method, plan, and error message.</p>
<p>Buying a higher plan without understanding the current usage route can waste money. If the terminal is using API billing, a subscription upgrade may not change the billing route until you authenticate correctly. If you are simply at a temporary plan limit, waiting may be enough.</p>
<p>Do not assume that a free download means free model access. The command line client and the service that powers its responses are separate parts of the setup. Always check the plan and billing details that apply to your account.</p>
