25:T3515,<p>Claude can read PowerPoint presentations when its built-in PowerPoint skill and code execution features are available. The skill is designed to read, parse and extract text from PPTX files, including slide content and speaker notes. There is one important detail: Anthropic&#39;s standard file upload page does not list PPTX among its ordinary document types. The PowerPoint skill is the route that adds this workflow.</p>
<p>This means the answer is yes, but it is not always as simple as dragging a PowerPoint file into every Claude chat. Your plan, workspace settings, enabled skills and the way you upload the deck can affect the result.</p>
<h2 id="short-answer">Short Answer</h2><p>Claude can analyze a PPTX file through Anthropic&#39;s PowerPoint skill. Enable Code execution and file creation, open Customize and Skills, and make sure the PowerPoint skill is available and enabled. Then upload the presentation and ask for a slide-by-slide summary, speaker-note extraction, a list of action items or a review of the deck.</p>
<p>Anthropic&#39;s <a href="https://github.com/anthropics/skills/tree/main/skills/pptx">PPTX skill on GitHub</a> says it is intended for any task involving a PPTX or POTX file, including reading, parsing, extracting text, editing and creating presentations. The skill includes a slide text script that can extract titles, text, tables, chart data, image alt text and speaker notes.</p>
<h2 id="what-the-question-really-means">What the Question Really Means</h2><p>Anthropic&#39;s <a href="https://support.claude.com/en/articles/8241126-upload-files-to-claude">Upload files to Claude guide</a> lists supported document formats such as PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON and XLSX. PPTX is not listed in that standard list.</p>
<p>At the same time, Anthropic provides a PowerPoint skill that can work with PPTX files. Its <a href="https://support.claude.com/en/articles/12512180-use-skills-in-claude">Use skills in Claude guide</a> says built-in skills are available on Free, Pro, Max, Ultra, Team and Enterprise plans, but they require code execution to be enabled. The PowerPoint skill is one of the built-in document skills.</p>
<p>The difference is between a normal file upload path and a skill-enabled workflow. If your file picker accepts the presentation and the skill is enabled, Claude can process it. If your account rejects the extension, do not assume the feature is broken for every user. Check the capability and skill settings first, then use the PDF fallback if the direct route is not available.</p>
<h2 id="practical-steps">Practical Steps</h2><p>For an individual Free, Pro, Max or Ultra account, Anthropic&#39;s current instructions are:</p>
<ol>
<li>Open Claude Settings.</li>
<li>Go to Capabilities.</li>
<li>Turn on Code execution and file creation. In the updated settings layout, this may be called Create and edit files.</li>
<li>Open Customize.</li>
<li>Select Skills.</li>
<li>Find the PowerPoint skill and turn it on if it is listed.</li>
</ol>
<p>Anthropic says the PowerPoint skill is available through its built-in skills. You do not need to install a third-party tool just to use the standard Claude.ai feature. The skill should be selected automatically when a relevant PowerPoint task is requested, once it is enabled.</p>
<p>For Team accounts, the organization must allow code execution and skills. For Enterprise, an owner may need to enable the features in organization settings. If you cannot see the skill, ask the workspace administrator to check the organization policy rather than changing account settings repeatedly.</p>
<p>Claude Code can also use skills that are enabled or synced from the same Claude account. The official help page says skills are available in Claude Code as well as Claude chat, with some setup requirements. The workflow may differ from the web app, so check the skill instructions for the environment you use.</p>
<h2 id="how-it-works">How It Works</h2><p>Once the capability is available, start with a specific task. Do not only write &quot;read this PowerPoint.&quot; Tell Claude what output you need and how much detail to include.</p>
<p>For a management deck, you could ask: &quot;Read this presentation slide by slide. Give me a one-paragraph summary of each slide, list the decisions requested from leadership, and identify any missing evidence. Keep the original slide order.&quot;</p>
<p>For a training deck, ask for the main lesson, key terms, examples and questions that a learner may ask. For a sales deck, ask Claude to list the claims, proof points, pricing references and calls to action. For a project review, ask for dates, owners, risks and unresolved decisions.</p>
<p>If the presentation includes speaker notes, say that you want them included. The PPTX skill&#39;s extraction workflow includes speaker notes, but a clear request helps Claude focus on them. If the deck has charts, ask for the chart title, axes, labels and the conclusion that the slide appears to make. Check the visual chart yourself if the exact value matters.</p>
<p>You can also ask for a structured output. For example, request a table with slide number, slide title, main message, evidence, action item and open question. This makes it easier to review a large deck without losing the source location of each point.</p>
<h2 id="what-claude-can-extract-from-a-pptx">What Claude Can Extract From a PPTX</h2><p>The official PowerPoint skill describes a workflow for extracting slide titles, text, tables, chart data, picture alt text and speaker notes. That is useful when you need a written summary or want to search for a specific phrase across a large deck.</p>
<p>The skill also provides a thumbnail script for creating a visual grid of the slides. This helps inspect layouts and see whether an image or chart supports the slide text. Text extraction and visual review are different tasks. A slide may contain a chart that is difficult to understand from its labels alone, or an image whose meaning is not described in alt text.</p>
<p>Ask Claude to separate facts from interpretation. For example, it can list what a chart labels, then explain what the chart may suggest. If the presentation contains a number that will be used in a report, verify it against the source data rather than relying only on the generated summary.</p>
<p>For a deck with many slides, process it in sections. Ask for slides 1 to 10 first, then the next group. This makes it easier to find mistakes and reduces the chance that a long answer skips a slide. Keep the slide numbers in the output so you can return to the original presentation.</p>
<h2 id="common-problems">Common Problems</h2><p>Use a PDF export as the first fallback. In PowerPoint, export or save the presentation as a PDF. In Google Slides, download the presentation as a PDF. Upload the PDF and ask Claude to analyze the pages in order.</p>
<p>Anthropic says Claude can analyze text and visual elements in PDFs with 100 pages or fewer. For PDFs from 101 to 1,000 pages, it processes text only and does not analyze visual elements. The upload guide lists a maximum of 1,000 PDF pages. If the deck is longer, split it into smaller sections before uploading.</p>
<p>A PDF is useful when the visual appearance of slides matters. If you only need text, you can export speaker notes or slide text into a DOCX, TXT or another supported format. Keep the slide numbers in the extracted text so the result can be checked against the original deck.</p>
<p>Avoid random online converters for confidential presentations. Use PowerPoint, Google Slides or an approved desktop tool. If you use a company deck, follow your organization&#39;s rules for moving files into an AI assistant.</p>
<h2 id="what-does-not-work">What Does Not Work</h2><p>The PowerPoint skill does not make every slide detail certain. A text extraction can miss a small label, a chart can be interpreted incorrectly, and a visual layout can carry meaning that is not present in the extracted text. A generated summary is not a substitute for checking the original slide when a number or claim matters.</p>
<p>The standard upload page also does not list PPTX as an ordinary document type. If your account cannot pass the file to the PowerPoint skill, repeatedly dragging the same file into the chat will not fix the capability setting. Use the PDF route or a supported text format instead.</p>
<h2 id="safety-and-limitations">Safety and Limitations</h2><p>A text summary cannot guarantee that every visual detail is correct. Small labels, complex diagrams, dense charts and embedded objects may need a human check. Ask Claude to identify which slides it could not interpret confidently.</p>
<p>The standard file upload guide lists a maximum of 500 MB per chat file and up to 20 files in one chat. Project files have a different limit and text extraction rules. These limits apply to the supported upload workflows; a skill or connected app may have its own constraints.</p>
<p>Code execution runs in a sandboxed environment. Anthropic&#39;s file creation guide explains that network access can be controlled by Team and Enterprise administrators. If you work with confidential data, check your organization&#39;s network and connector policies before enabling extra access.</p>
<p>Do not treat a generated deck summary as a verified record. A model can misread a chart, skip a footnote or combine two similar slide titles. For legal, financial, medical or compliance decisions, check the original slides and source files.</p>
<h2 id="prompts-that-make-powerpoint-analysis-more-useful">Prompts That Make PowerPoint Analysis More Useful</h2><p><strong>Executive summary:</strong> &quot;Summarize this deck for a senior manager in 10 bullet points. Keep the slide numbers and separate facts from recommendations.&quot;</p>
<p><strong>Speaker notes:</strong> &quot;Extract the speaker notes from every slide. Show the slide number, slide title and notes. Do not invent notes for slides that have none.&quot;</p>
<p><strong>Risk review:</strong> &quot;Find every slide that mentions a risk, delay, cost increase or dependency. List the exact wording and slide number, then explain why each item may need follow-up.&quot;</p>
<p><strong>Data review:</strong> &quot;List every chart and table. Extract the labels and values you can read, identify the source if shown, and mark any unclear figures for manual checking.&quot;</p>
<p><strong>Presentation feedback:</strong> &quot;Review the story flow from opening to conclusion. Identify repeated points, missing transitions and slides that contain too much text. Do not rewrite the deck yet.&quot;</p>

<li>Use a PDF export if direct PPTX processing is not available.</li>
<li>Check charts, labels and sensitive details before relying on the summary.</li>
