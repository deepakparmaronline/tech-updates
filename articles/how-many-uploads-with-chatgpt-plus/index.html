How Many Uploads Does ChatGPT Plus Allow? Limits Explained

ChatGPT Plus can upload up to 80 files every three hours, subject to peak limits. Learn file size caps, project limits, storage rules, and reset timing.

Tech UpdatesNov 10, 20269 min read read
Key takeaways
  • OpenAI currently documents up to 80 file uploads every three hours for users, while Free accounts have a lower daily allowance.
  • The 80-file figure is a rolling upload-rate limit, not a promise of 80 files in one chat or a fixed daily quota.
  • Plus projects can hold up to 25 files each, and only 10 files can be uploaded at the same time.
  • Storage and file-size limits are separate from the rolling upload rate.
  • OpenAI may lower upload limits during peak periods, and failed attempts can sometimes count.

If you use ChatGPT Plus for reports, spreadsheets, PDFs, or images, the upload limit can be confusing. OpenAI publishes a general rolling upload rate, separate storage caps, and a different limit for files inside Projects. These numbers answer different questions, so reaching one limit does not always mean you have reached the others.

The short answer is that OpenAI currently says users can upload up to 80 files every three hours. Free users have a lower daily limit, and OpenAI may lower the rate during busy periods. Plus users also have a separate Project limit of 25 files per Project. The details below explain what each number means and what to do when ChatGPT says you have reached a limit.

Short Answer

For ChatGPT Plus, use 80 files every three hours as the published upper upload rate, not as a guaranteed allowance. OpenAI says it may lower the limit during peak hours. The Help Center does not promise that every Plus account will always be able to upload exactly 80 files in every three-hour period.

A Project has a different limit. OpenAI currently lists up to 25 files in each Project for Plus and Go users, with a maximum of 10 files uploaded at one time. A user can create multiple Projects, but the shared storage cap still applies across chats, Projects, and custom GPT knowledge.

There is also a file-size limit. Images have a 20 MB limit. Text and document files are capped at 2 million tokens per file, while CSV and spreadsheet files have an approximate 50 MB limit that can depend on the data. A file can therefore fail because it is too large even when your upload-rate allowance is available.

What the Question Really Means

People often ask how many uploads ChatGPT Plus allows when they see a message that says the upload limit has been reached. That message can refer to more than one restriction. The first is a rate limit, which controls how many files you can send over a period of time. The second is storage, which controls how much uploaded data is saved across your account or organization.

The third restriction is a location-specific count. A Project has a maximum number of files that can be attached to it. A custom GPT has its own knowledge-file rules. These limits do not replace the account-wide upload rate. You can have space left in a Project but still hit the rolling upload rate, or have rate capacity left but be unable to add another file to a full Project.

The file itself can also be the problem. A large PDF, a spreadsheet with heavy rows, or a high-resolution image may exceed the limit for its format. If you see an upload error, identify which limit is involved before deleting files or changing plans.

How It Works

The 80-file allowance is a rolling three-hour window. It is not a midnight reset and it is not a fixed number of uploads per conversation. If you upload files in several chats, those uploads still contribute to your account's recent activity. The exact time at which an upload becomes available again depends on when it was counted in the rolling window.

OpenAI also says that failed upload attempts can sometimes count toward the rate limit. Repeatedly selecting the same large file may therefore make the situation worse. If an upload fails, check the file type and size first. If the file is valid, wait for the limit to recover rather than clicking upload again and again.

Storage is shared across the places where you use files. OpenAI lists a 25 GB cap per end user and a 100 GB cap per organization. Files in chats, Projects, and custom GPT knowledge can all contribute to that shared cap. This is why deleting one old chat may help with storage even when the upload-rate window has not reset.

Project limits are separate again. Plus and Go users can currently add up to 25 files to a Project. OpenAI says only 10 files can be uploaded at the same time. If you need to work with more documents, split them into multiple Projects or combine related material into a smaller number of files where that makes sense.

Practical Steps

First, check the type of work you are doing. If you are preparing a long-running research project, create a Project and add the core documents there. Keep the number of files below the 25-file limit and upload them in groups of 10 or fewer. This makes it easier to see which files belong to the task and reduces repeated uploads.

Second, check the size of every file before sending it. Resize an image if it is above 20 MB. Export a Google document as PDF or DOCX rather than trying to upload a shortcut file. For spreadsheets, remove unused sheets and rows or split a very large workbook into smaller parts. A CSV file can be near the approximate 50 MB limit even when it looks small in a spreadsheet application.

Third, check saved storage. In ChatGPT, open Settings and then Storage to review saved-file usage. This page helps with the storage cap, but it does not show the remaining three-hour upload allowance. OpenAI says there is currently no meter that tells you exactly how many uploads remain in the rolling window.

Fourth, if you hit a rate limit, wait and retry once the window has had time to recover. If the message appears after very few uploads, confirm that you are using the correct account and subscription. Check the OpenAI status page if uploads are failing across the service, not only for one file.

Common Problems

A common mistake is counting only the files in the current chat. The rate limit is not described as a per-chat allowance. Uploads in other chats and Projects can matter. A custom GPT knowledge file can also contribute to the shared storage cap, so the account may have less space than the current conversation suggests.

Another problem is confusing storage with upload rate. Deleting old files can help if the account has reached its storage cap, but it does not necessarily restore the rolling upload rate immediately. The two limits are managed separately. If you have just uploaded many files, waiting may be the only way to clear the rate limit.

The third problem is the file itself. A PDF can be below 512 MB but still exceed the two-million-token limit for text and document files. A spreadsheet may hit its approximate 50 MB cap. An image can exceed the 20 MB image limit even when the file format is supported. Check the limit for the actual file type instead of relying on one general maximum.

What Does Not Work

Switching from a browser to the mobile app does not create a new account upload allowance. The rate limit is tied to the account, not to a single device. Opening another conversation also does not create a fresh quota. If you are near the limit, moving the same files to a different chat can add confusion without solving the restriction.

Deleting a Project is not a reliable way to recover a rolling rate allowance. It may help with stored files if those files are removed from your account, but the three-hour rate window is a different control. Do not delete useful project material until you know that storage is the problem.

Upgrading is not a guaranteed fix for every upload error. Plan features and file limits can change, and the Help Center may apply temporary peak-hour reductions. Before changing plans, identify whether you have reached the upload rate, storage cap, Project file count, or a per-file size limit. The ChatGPT pricing page explains plan differences, while the upload guide explains the file rules.

Safety and Limitations

Upload only files you are allowed to share. A file may contain names, account numbers, private business information, or personal details that are not needed for the task. Remove unnecessary data before uploading, especially when a spreadsheet contains more rows or columns than the analysis requires.

Keep a separate copy of important documents. ChatGPT is a working environment, not your only archive. If you delete a chat or remove a Project to free storage, make sure you still have the original file somewhere safe. Also remember that a successful upload does not mean every detail in a document will be interpreted correctly. Ask ChatGPT to identify the pages, sheets, or sections it used, then check important figures against the source.

OpenAI's limits can change. The numbers in this guide reflect the current Help Center pages reviewed on November 10, 2026. Check the official upload guide and Project help page before planning a large batch of files, because a limit can be adjusted without changing the Plus plan name.

Key Takeaways

  • The published upload rate is up to 80 files every three hours, with possible peak-hour reductions.
  • Plus Projects currently allow up to 25 files each, with 10 uploads at one time.
  • Storage, file size, and rolling upload rate are separate limits.
  • Settings > Storage shows saved-file usage, not the remaining rolling quota.
  • Wait before retrying repeated failed uploads.

FAQ

Is the 80-file limit only for ChatGPT Plus?
OpenAI describes it as a general user upload rate and separately says Free users have a lower daily allowance. Treat 80 as the published upper rate for paid use, not as a Plus-only promise.

Does the 80-file limit reset at midnight?
No fixed midnight reset is documented. The Help Center describes a rolling three-hour window, so the timing depends on when earlier uploads were counted.

Can I upload more than 25 files to a Plus Project?
The current Project limit for Plus is 25 files. You can create another Project for a separate set of documents, but shared account storage still applies.

How many files can I upload at one time?
OpenAI says up to 10 files can be uploaded at the same time in Projects. This is different from the total number of files allowed in a Project.

Why does ChatGPT say I reached the limit after only a few uploads?
You may have used uploads in other chats or Projects, reached shared storage, or had failed attempts counted. Check Settings > Storage and review the file size before retrying.

Can I see the exact number of uploads remaining?
OpenAI says ChatGPT does not currently display the remaining rolling upload quota. You can check saved storage, but you may need to wait for the rate window to recover.
