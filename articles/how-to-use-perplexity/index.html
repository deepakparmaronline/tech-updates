How to Use Perplexity: Search, Research and Projects

Learn how to use Perplexity for quick searches, deeper research, file analysis and Projects. Get better answers and check every important citation.

Perplexity works best when you treat it as a research assistant rather than a box that gives final answers. Ask a focused question, inspect the source links, then use follow-up questions to narrow the result. For larger tasks, switch to Research mode, upload relevant files or keep ongoing work in a Project. Some advanced features depend on your plan, so the controls you see may differ from another account.

Short Answer

What the Question Really Means

Using Perplexity can mean a quick web search, a longer research task, file analysis or an ongoing project. These workflows use different controls and can have different plan limits, so start by deciding what result you need instead of treating every question as the same kind of search.

Open Perplexity on the web or in the mobile app, enter a clear question and review the answer with its citations. Add the topic, date range, location or output format when those details matter. Ask follow-up questions to refine the answer instead of starting over.

Perplexity says Pro Search is no longer a separate toggle. When it is included in your plan, Search uses Pro Search automatically up to your plan's limit. Use Research mode when you need a longer report based on a multi-step investigation. Use file uploads when you need the assistant to analyse your own documents.

How It Works

Perplexity searches for information, reads sources and creates a written answer with links to the material it used. That is different from a traditional search page that mainly gives you a list of links. You can ask a follow-up question and keep the conversation focused on the same topic.

The answer is still generated by an AI system. A citation can point to a relevant page without proving that every sentence in the answer is correct. Open the original source, check its date and confirm that it supports the exact statement. This is especially important when the answer includes prices, product limits, laws or recent events.

Perplexity offers different modes for different tasks. Search is useful for focused questions and follow-ups. Research mode performs a longer investigation and produces a report. Model selection can also be available before you start a search, depending on your plan and the current interface.

Practical Steps

1. Open the official website or mobile app

Go to perplexity.ai or open the official Perplexity app. Sign in if you want to keep your sessions and use account features. If you are trying the service for the first time, start with a question that has a clear answer and a source you can check.

Do not install a browser extension or mobile app just because it uses the Perplexity name. Use the official product page and app-store listing. This reduces the risk of giving your account access to an unrelated service.

2. Write a question with useful context

A short question can work for a simple fact. A research question should include the context that changes the answer. Instead of asking "Which project tool is best?", ask "Compare project management tools for a five-person remote design team. Prioritise guest access, recurring tasks and public pricing. Use current vendor documentation."

You can also specify the output. Ask for a comparison table, a short summary, a list of disagreements between sources or a step-by-step explanation. If the answer must be current, give a date range and ask Perplexity to show the publication date for each source.

3. Review the answer and open citations

Read the summary, then open the citations that support the important claims. Check whether the source is official, current and relevant. A vendor pricing page is usually better for a current price than an old comparison blog. A government or standards document is better for a legal or technical rule than a forum comment.

If a source does not support the claim, ask Perplexity to correct it and show the relevant passage. You can also open the original page and compare the wording yourself. For a high-impact decision, use more than one reliable source and keep the source list with your notes.

4. Ask follow-up questions

Use the same session to ask what changed, which sources disagree or what assumptions the answer uses. A follow-up such as "Compare only the products with public pricing" is more useful than asking the same broad question again.

If the conversation moves to a different task, start a new session. This helps keep the source context clear. If you are doing a long-running project, use a Project rather than letting one search thread become a large collection of unrelated questions.

When to Use Search, Research and Model Selection

Search is the right starting point for a direct question, a product lookup or a focused comparison. Perplexity's help page says Search uses Pro Search automatically when it is included in your plan. You do not need to look for a separate Pro Search toggle. The plan limit still applies.

Research mode is for a question that needs several searches and a structured report. Perplexity says Research can perform dozens of searches, read many sources and refine its research plan as it learns more. Free users have limited access, while Pro subscribers receive extended access. The mode can take several minutes, so do not use it for a simple definition.

If model selection is available, choose a model that fits the task or leave the selector on Best. A quick factual lookup may not need the same model as a complex analysis. The available models and usage limits can change, so use the current model menu rather than relying on an old list from a tutorial.

How to Use File Uploads

You can attach a file with the plus or attach control in the search box, or drag a supported file into the session. Perplexity's help page lists text, code, PDF, image, audio and video files. It says the current per-file limit is 40 MB, while upload allowances depend on the plan and reset on a rolling weekly basis.

Ask a precise question about the file. For a PDF, request a summary of the argument and a list of sections that support it. For a spreadsheet, name the columns and the calculation you want. For code, ask for an explanation of a specific function or an error rather than a general review of an entire repository.

Perplexity says audio and video uploads are transcribed so spoken content can be searched. Its help page also says visual scenes from video are not indexed or searchable at this time. Do not assume the assistant has watched every frame. If a video contains important visual information, provide screenshots or describe the scene separately.

Remember that uploads have plan limits. The help page says allowances roll forward as older uploads leave the weekly window; there is no fixed weekly reset day. If you reach the limit, the product shows a message when you try to attach another file.

How to Use Projects for Ongoing Work

Projects are persistent Perplexity workspaces. The current Help Center says they keep searches, Computer tasks, files, instructions and connected tools together. Perplexity's changelog says Projects evolved from Spaces and that existing Spaces were migrated automatically.

Create a Project for work that continues over several sessions. Give it a clear title, add instructions that explain the goal and preferred output, then add the files and connectors it needs. For example, a project for market research can store source documents, product notes and a list of competitors. This is more useful than pasting the same context into every new search.

Projects are private by default, according to the Help Center. You can invite collaborators and set roles. Files and connector copies have their own rules, so do not assume that updating a file in Google Drive or another connected service automatically updates the copy already stored in a Project. Ask Perplexity to fetch the latest version or add it again.

Projects are most useful when you use Perplexity Computer and want work to continue across tasks. They are not required for a quick web search. If you only need one answer, a normal Search session is simpler.

Common Problems

The first mistake is asking a broad question and accepting the first summary. Add the audience, time range and criteria that matter. The second is trusting a citation without opening it. The third is asking Research mode to answer a simple question, which can use more time and plan allowance than needed.

Another mistake is mixing files from unrelated projects in one session. A source from an old brief can affect a later answer. Keep sessions focused and use Projects to separate ongoing work. If you upload confidential material, check your organisation's rules and Perplexity's current privacy settings before sharing it.

Do not treat a generated comparison table as a verified product test. Perplexity can summarise vendor pages, but it does not automatically test each tool or confirm every feature. If you need to choose software, verify the vendor documentation and pricing, then run a small trial with your own workflow.

What Does Not Work

Perplexity should not be treated as a source that proves its own answer. A citation may be outdated, indirect or only partly relevant. Open the original page, check its date and confirm that it supports the specific statement before relying on it.

Safety and Limitations

Do not upload passwords, private customer records or confidential company files to a personal account unless your organisation has approved that use. Connected sources can bring business documents into a session or Project, so check which accounts and folders are connected.

Perplexity's own help pages explain that features and limits vary by plan. Search, Research, file uploads, model access and Projects may not be identical for every user. Check the in-product controls and current Help Center if a feature is missing or a limit appears.

Key Takeaways

  • Start with a clear question and add context that changes the answer.
  • Use Search for focused questions and Research mode for multi-step reports.
  • Open citations and verify the original sources.
  • File uploads support several formats, but limits depend on your plan.
  • Projects help keep ongoing work, files and instructions together.

FAQ

How do I start using Perplexity?

Open the official website or app, type a clear question and review the answer with its source links. Sign in if you want to keep sessions and use account features.

Is Pro Search a separate button?

No. Perplexity says Pro Search is no longer a separate toggle. Search uses it automatically when it is included in your plan, up to the plan limit.

What is the difference between Search and Research mode?

Search is useful for focused questions and follow-ups. Research mode performs a longer investigation and produces a report. Free access is limited and Pro gives extended access.

Can Perplexity read PDF and video files?

It supports PDFs, text, code, images, audio and video uploads. Audio and video speech is transcribed, but the current help page says visual scenes in video are not indexed.

What are Perplexity Projects?

Projects are persistent workspaces for searches, Computer tasks, files, instructions and connected tools. They help keep long-running work in one place.

Can I trust every Perplexity citation?

No. Open the original source, check its date and make sure it supports the exact claim. For important decisions, compare more than one reliable source.
