1b:T2bc9,<h2 id="short-answer">Short Answer</h2><p>For a native Claude Code installation, open a terminal and run <strong>claude update</strong>. If you installed it with Homebrew, WinGet, or a Linux package manager, use that manager&#39;s upgrade command. For a global npm install, Anthropic documents <strong>npm install -g @anthropic-ai/claude-code@latest</strong>. Native installations check for updates at startup and periodically while running. An installed update takes effect the next time you start Claude Code.</p>
<p>If the command fails, do not immediately remove the installation or delete configuration files. First check your installed version, identify how Claude Code was installed, and run its diagnostic command. The official <a href="https://code.claude.com/docs/en/setup">Claude Code setup guide</a> explains the supported installation paths and update options.</p>
<h2 id="what-the-question-really-means">What the Question Really Means</h2><p>People usually search for an update because they want a new feature, a bug fix, or a security improvement. They may also see a notice in the terminal and wonder whether they need to download a new installer.</p>
<p>These are slightly different situations. An automatic update may already have downloaded a release in the background. A manual update asks the installed program to check and apply the latest version. A fresh installation is a separate step and is usually not the first thing to try.</p>
<p>Your installation method matters too. Claude Code&#39;s current setup guide recommends the native installer and also documents Homebrew, WinGet, Linux package managers, and npm. Those installation methods do not all update in the same way. A company may also manage installation through an enterprise environment. The correct fix depends on which method is active on your computer.</p>
<h2 id="how-it-works">How It Works</h2><p>Claude Code&#39;s update behavior depends on how you installed it. Native installations check for updates at startup and periodically while running. Updates install in the background and take effect the next time you start the tool. Homebrew, WinGet, and Linux package manager installations do not auto update by default, so use the matching package manager. For npm, Anthropic documents npm install -g @anthropic-ai/claude-code@latest. For a native install, claude update applies an update immediately. Updating Claude Code does not automatically update your project dependencies.</p>
<p>The <a href="https://code.claude.com/docs/en/cli-usage">official CLI reference</a> explains command behavior and should take priority over old community posts.</p>
<h2 id="practical-steps">Practical Steps</h2><h3 id="1-check-the-version-first">1. Check the version first</h3><p>Open the terminal you normally use for Claude Code. Run claude --version and note the result. This gives you a baseline for checking whether the update worked. If the command is not found, that is an installation or PATH issue, not proof that the service is down.</p>
<h3 id="2-use-the-command-for-your-installation">2. Use the command for your installation</h3><p>For a native installation, run claude update and let the process finish. For a global npm installation, Anthropic documents npm install -g @anthropic-ai/claude-code@latest. For Homebrew, use brew upgrade claude-code or brew upgrade claude-code@latest, depending on the cask. For WinGet, use winget upgrade Anthropic.ClaudeCode. Linux package manager installations should use the upgrade command for apt, dnf, or apk. Read the terminal output and save any error message rather than assuming the command succeeded.</p>
<h3 id="3-restart-claude-code">3. Restart Claude Code</h3><p>Close the current Claude Code session and start it again. Then run claude --version once more. Compare the new result with the version you recorded before updating. If the version is unchanged, check whether the update command reported a failure or whether your terminal is finding a different installation.</p>
<h3 id="4-check-the-installation-method">4. Check the installation method</h3><p>If you installed Claude Code globally through npm, use the instructions for that installation. If you moved to a local or native installation, follow Anthropic&#39;s migration and installation guidance. Avoid installing multiple copies just to make an update work. Multiple copies can leave one terminal using an old executable while another uses a newer one.</p>
<h3 id="5-run-diagnostics-when-needed">5. Run diagnostics when needed</h3><p>Run claude doctor and review its output. The setup guide recommends this command for checking installation details. If you use a managed company computer, check your team&#39;s software policy before changing installation paths or using administrator privileges.</p>
<h3 id="6-keep-project-work-safe">6. Keep project work safe</h3><p>Updating the CLI is not the same as upgrading your application. Before troubleshooting with a reinstall, commit your source changes or make a backup. That gives you a clear way to recover your own work if you later need to repair the development environment.</p>
<h2 id="common-problems">Common Problems</h2><p><strong>The command is not found.</strong> The terminal may not have the installation directory on its PATH, or Claude Code may not be installed in the environment you opened. Check the terminal where it worked previously and inspect the installation instructions for your operating system.</p>
<p><strong>The updater reports a permission error.</strong> Do not immediately add sudo to an npm command. Anthropic specifically warns against using sudo for its global npm installation because it can create permission and security problems. Follow the official guidance for fixing npm permissions or migrating to the recommended installer.</p>
<p><strong>The update completes but the version looks old.</strong> Restart Claude Code, run the version command again, and check which executable your shell is using. On Unix like systems, the command which claude can help identify the executable path. On Windows, use the command lookup supported by your shell.</p>
<p><strong>The update hangs or cannot download files.</strong> Check your network connection, proxy or VPN settings, and any company firewall rules. Retry only after confirming the connection is stable. If the same error returns, use the official troubleshooting guide and keep the full error text.</p>
<p><strong>A team policy blocks the update.</strong> Enterprise environments can control which tools and versions are allowed. Ask the administrator to confirm the supported version instead of trying to bypass a policy.</p>
<h2 id="what-does-not-work">What Does Not Work</h2><p>Repeatedly reinstalling the tool is not a good first response. It can make the environment harder to understand, especially when the computer has both a global and a local installation. Deleting configuration directories is also risky because those files may contain preferences that have nothing to do with the update failure.</p>
<p>Avoid copying a command from an old forum post without checking its source. Installation instructions can change, and commands that download and run a script have more impact than a simple version check. Prefer Anthropic&#39;s current documentation and inspect commands before running them.</p>
<p>Do not assume that a new Claude Code version automatically updates Node.js, your project&#39;s packages, Git, or other developer tools. Treat each component as a separate update with its own compatibility requirements.</p>
<h2 id="safety-and-limitations">Safety and Limitations</h2><p>The updater needs a working connection and permission to modify its installation. A managed device may block one or both. A new release may also behave differently from the version you used before, so read relevant release notes when a change affects a production workflow.</p>
<p>Keep sensitive project files and credentials out of terminal logs that you share publicly. If you ask a community for help, remove access tokens, private repository paths, customer data, and other confidential details from the output.</p>
<p>Automatic updates can be useful, but teams that require a controlled release process may prefer a documented update window. In that case, follow the organization&#39;s approved installation method and test the new version on a noncritical task before using it for important work.</p>
<h2 id="key-takeaways">Key Takeaways</h2><ul>
<li>Run claude update for a manual update.</li>
<li>Restart Claude Code and confirm the version.</li>
<li>Use claude doctor before making bigger changes.</li>
<li>Follow the installation path already used on your computer.</li>
<li>Back up important project work before repairing the environment.</li>
</ul>

If you use WSL or Git Bash, run the command in the environment where Claude Code is installed. Restart the session and check the version afterward.</p>
<h3 id="how-do-i-update-claude-code-on-macos-or-linux">How do I update Claude Code on macOS or Linux?</h3><p>For a native installation, run claude update. For Homebrew, use brew upgrade claude-code or brew upgrade claude-code@latest. For npm, use npm install -g @anthropic-ai/claude-code@latest. For apt, dnf, or apk, use the package manager&#39;s upgrade command. If an update fails, check the installation method and run claude doctor.</p>

Homebrew, WinGet, and Linux package manager installs do not auto update by default. After an update installs, restart Claude Code to use the new version.</p>
<h3 id="how-do-i-stop-automatic-updates">How do I stop automatic updates?</h3><p>Anthropic documents a global autoUpdates setting and the DISABLE_AUTOUPDATER environment variable. Read the current setup guide before changing these settings, especially on a managed computer.</p>
