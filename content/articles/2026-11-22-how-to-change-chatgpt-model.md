You can change the ChatGPT model from the model picker before sending a message. On the web, look near the message composer. On Android and iPhone, look at the top of the conversation. Select the model or reasoning option you want from the choices shown in your account. The list is not identical for every user because access depends on the plan, app rollout and workspace settings.

## Short Answer

Open a conversation and tap or click the model name. Choose an available model from the menu. If the menu offers thinking levels, choose the effort level that fits the task. Use a fast option for everyday questions and a higher reasoning option for work that needs more careful analysis, when your plan includes it.

The model picker is an account feature, not a setting that must be changed in the phone's Android or iOS settings. You do not need to create a new account or reinstall ChatGPT just to switch models. If the option is missing, check whether you are in the correct account and whether your plan or organisation provides access.

OpenAI's [model guide](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt) explains current model and thinking choices. Its [ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) document changes to the picker over time. These official pages are more reliable than old screenshots because the menu can change during a rollout.

## What the Question Really Means

People often use the word model to mean three different things: the AI model, the response speed or reasoning setting, and the tool or feature used in a chat. They are related but not identical. Selecting a different model changes which AI system handles the next response. Selecting a thinking level changes how much reasoning effort an available model uses. Selecting a tool such as data analysis or web search changes the work the assistant can perform.

A model picker can show different names based on plan and account access. A personal paid account may show options that are not available to a Free account. A work or school workspace can also restrict models through administrator settings. A feature may be announced publicly but still roll out gradually, so two people using the same app version may see different choices.

It is useful to decide what you need before switching. A simple question does not always need the highest reasoning setting. A coding task, detailed research request or complex comparison may benefit from a model designed for more involved work. If a model is slower or has a tighter usage allowance, save it for tasks where the difference matters.

## How It Works

The model picker tells ChatGPT which available model should handle a response. When you select a choice, the next message is processed using that selection, subject to any automatic routing or product rules described in the interface. The picker may also include an option that lets ChatGPT decide when to use more reasoning. The exact label can change as OpenAI updates the interface.

On web, the model picker appears close to the message composer. On mobile, it is normally at the top of the conversation. If you cannot see it, make sure the chat is open and the app is updated. In a managed workspace, the organisation may have a smaller model list than a personal account.

Some interfaces separate the model choice from the thinking effort. A model is the underlying system. Thinking effort controls how much time or computation the model uses for a response. A higher effort setting can help with multi step reasoning, but it does not guarantee a correct answer. You should still check important calculations, sources and code.

## Practical Steps

### Change the model on the web

1. Open ChatGPT in your browser and sign in to the correct account.
2. Open an existing conversation or start a new one.
3. Find the model name near the message composer.
4. Click the model name to open the picker.
5. Select one of the models shown in the list.
6. If a thinking or effort control appears, choose the level you need.
7. Send your next prompt and check the response.

If the interface shows a Configure or settings option inside the picker, open it to review available controls. Do not assume a setting described in an older tutorial is still present under the same label. OpenAI has changed the location and names of model and thinking controls across releases.

### Change the model on Android

1. Open the ChatGPT app.
2. Sign in to the account you want to use.
3. Open a conversation.
4. Tap the model name at the top of the chat.
5. Review the available choices.
6. Tap the model you want to use.
7. Return to the conversation and send a new message.

If the picker does not appear, update the app through the Play Store and reopen it. A force close and restart can help refresh the interface after an update. Do not clear app storage as the first step because it can remove local app data and sign you out.

### Change the model on iPhone

1. Open ChatGPT on your iPhone.
2. Open the conversation where you want to continue.
3. Tap the model label near the top of the screen.
4. Select an available model or reasoning option.
5. Send the next message.

If you use ChatGPT through a work or school account, check whether the workspace has its own model access rules. A personal account and a managed workspace can show different choices even on the same device.

### Pick a model for the task

Use the model description in the picker as the first guide. For everyday writing, quick explanations and simple questions, a faster model may be enough. For coding, long document analysis or research, consider a model and effort level designed for more complex work. If you are unsure, start with the default option and switch only when the answer needs more depth.

## Common Problems

### The model picker is missing

Check that you are signed in and viewing a normal conversation. Update the app, refresh the browser and open a new chat. If you are using a managed workspace, ask the administrator whether model selection is restricted. A model rollout can also be staged, so a feature may not appear for every account at the same time.

### The model appears but cannot be selected

The option may be unavailable under your current plan, account region or workspace policy. Some options can be disabled when a usage limit is reached. Read the message shown in the picker rather than repeatedly tapping the same option. If the account is managed, the workspace owner may need to change access.

### The selected model changes back

Check whether the conversation is using an automatic selection option. Some interfaces can route a request based on task or availability. Select a named model if you need a specific choice and the option is available. If the setting keeps changing unexpectedly, record the app version and the exact model label before contacting support.

### The menu looks different from a tutorial

The model picker changes over time. A screenshot from an older release may show a different button location, model name or thinking label. Use the current help page and the labels visible in your account. Avoid following instructions that ask you to install unofficial extensions or modified apps to unlock a model.

## What Does Not Work

Changing the model in ChatGPT does not automatically upgrade your subscription. It does not remove usage limits or grant access to features that your plan does not include. A model name in a news article or public announcement does not mean it is available in every account.

Reinstalling the app is also not a reliable way to unlock a model that is restricted by plan or workspace. Clearing browser cookies may sign you out, but it will not change account entitlements. Avoid third party scripts that claim to reveal hidden models or bypass the model picker. They can expose your account or session data.

## Safety and Limitations

Model availability, names and usage limits can change. A model that is visible today may be renamed, moved or retired later. Before building a workflow around one model, check the current official help page and confirm that the account you use has access.

A higher reasoning setting is not a substitute for checking the result. Verify facts against primary sources, test generated code in a safe environment and review calculations before using them in a business decision. If you share private documents, follow your organisation's data policy and check which workspace is active.

## Key Takeaways

- Choose from the options visible in your account.
- Model access depends on plan, rollout and workspace permissions.
- Thinking effort and model selection are related but different controls.
- Updating the app can fix an old interface, but it cannot grant a plan entitlement.

## FAQ

### How do I change the model in ChatGPT?

Open the model picker near the web composer or at the top of a mobile conversation. Select an available model and send your next prompt.

### Can I change the model after starting a chat?

Yes, when the picker allows it. Select another available option before sending the next message. Some workspace or product rules may limit the choices.

### Why can I not see a model in ChatGPT?

The model may not be included in your plan, may still be rolling out, or may be restricted by your workspace administrator.

### Does changing the model create a new chat?

You can usually change the model inside the current conversation. The exact controls depend on the app version and account.

### Can Free users choose every ChatGPT model?

No. Free and Go accounts have different model and thinking options from paid accounts. Check the current plan details.

### What is the difference between a model and thinking level?

A model is the AI system that generates the response. A thinking level changes the reasoning effort available for that model.
