If you want to keep one Claude conversation private, it is natural to look for a password or PIN option. Anthropic's current public help pages describe chat history, memory controls, Incognito Chats, and sharing settings, but they do not document a separate password lock for an individual conversation.

That distinction matters. A private chat is not the same as a password-protected chat. Incognito mode can keep a conversation out of normal history and memory, but it does not lock the account on a device that is already signed in. This guide explains the available controls and the safest way to use them.

## Short Answer

There is no per-chat password or PIN feature documented in the current Claude help pages reviewed for this guide. You cannot rely on a separate password being required whenever someone opens one specific conversation. If another person can use your unlocked device and your signed-in Claude account, they may be able to open the same account.

Use your device's own screen lock, keep your operating-system account private, and sign out of Claude when you use a shared computer. If your goal is to stop Claude from saving or using one conversation as memory, use Incognito Chat or the per-chat memory control. Those settings change how Claude handles the conversation; they do not add access protection.

Also check whether you have shared a conversation. A public chat link is a separate sharing feature. Anyone who has that link can view the shared snapshot, so do not use it for private material. If you already created a link, review the sharing settings and turn it off if the link should no longer work.

## What the Question Really Means

The phrase password-protected chat can refer to several different needs. You may want to stop another person who uses your laptop from reading a conversation. You may want Claude not to remember information from a chat. You may want a conversation to disappear from your history. Or you may want to stop a shared link from being opened by someone outside your account.

Those are different controls. A device password protects access to the computer or phone. An account sign-in protects access to Claude itself. Memory controls affect whether Claude uses or saves information for future conversations. Incognito Chat changes whether the chat appears in normal history. Sharing settings control whether another person can open a link.

Using the wrong control can create a false sense of privacy. For example, starting an Incognito Chat does not stop a person who can open your signed-in browser from using the account. Turning off memory does not hide the conversation from the chat list. Deleting a chat does not necessarily remove every memory entry that may have been created from it.

## How It Works

Anthropic's Incognito Chat feature is designed for a conversation that should not be saved to normal chat history or Claude memory. On the web, the help page says to start a new chat outside a Project and select the ghost icon. The conversation is not added to your normal history and Claude does not use it to build memory from that chat.

Incognito does not mean instant deletion. Anthropic says these chats can be retained for 30 days for safety. On Team and Enterprise plans, Incognito Chats can also be included in organizational data exports and follow the organization's retention policy. A company administrator may therefore have different compliance visibility than an individual user expects.

There is also a separate memory control for a single chat. Anthropic says you can turn off Memory from the plus menu before sending the first message. In that mode, Claude does not use or add memory for the chat, but the conversation remains in your history. You can still find it later, so this option is not the same as Incognito Chat.

Claude can also search and reference past conversations when that feature is enabled for your account. The help page describes a setting that controls whether Claude can search previous chats. Turning that setting off limits that kind of cross-chat reference, but it does not create a password lock or remove the conversations from your history.

## Practical Steps

If you use Claude on a shared computer, begin with the device. Use a separate operating-system account, set a strong screen-lock password, and lock the screen whenever you leave. Do not save your sign-in session on a public or shared browser. When you finish, sign out of Claude and close the browser window.

If you want one conversation not to become part of Claude's normal history, start a new chat outside a Project and select the ghost icon to use Incognito Chat. Check that the interface shows the Incognito state before you enter information. Do not assume that opening a normal chat and then switching a setting later will change the earlier messages.

If you want the chat to stay in history but not affect memory, start a new conversation and turn off Memory in the plus menu before the first message. This is useful for a one-off question where you still want to find the conversation later. If you want to stop Claude from searching earlier chats, open Settings and look for the Search and reference chats control in the Memory area.

Finally, review sharing. Open a conversation's Share menu or the shared-chats area in Settings. If a public link is active, turn it off when it is no longer needed. Anthropic says anyone with the link can open the snapshot, even if they do not have a Claude account. Treat a public link as public, even if you only sent it to one person.

## Common Problems

The most common misunderstanding is that Incognito Chat is a private vault. It is not. It changes how the conversation is saved and used for memory, but it does not ask for a second password when the account is already open. A person who can use your unlocked device may still be able to interact with the signed-in account.

Another misunderstanding is that turning off memory removes the conversation from history. Anthropic documents a separate per-chat memory control. The chat remains in history, and Claude may still find it through past-chat search if that feature is enabled. Use Incognito when the goal is to keep a conversation out of normal history.

A third problem is shared links. A private conversation can become visible to other people if you create a public share link. The link is not restricted to the person you sent it to. Someone can forward it or copy the content. Turning off the link prevents new visitors from opening the Claude-hosted snapshot, but it cannot remove screenshots or copies already made elsewhere.

Team and Enterprise accounts need extra care. Incognito Chats can appear in organizational data exports and can follow an administrator's retention policy. A feature that keeps a chat out of a user's normal history does not necessarily remove it from all compliance systems.

## What Does Not Work

There is no documented way to add a unique password to one existing Claude conversation. Do not rely on a browser bookmark, a renamed chat, or an Incognito setting as a substitute for an account lock. Those steps do not stop another person who can already use your signed-in session.

Turning off memory is not a way to hide a chat. The conversation remains in the history list. Deleting a conversation is also not the same as immediately removing all associated data. Anthropic says deleted consumer chats are removed from history immediately and deleted from backend systems within 30 days, subject to its stated exceptions.

Do not send a public link to a chat that contains private documents, client information, account details, or personal messages. A link that is hard to guess is still a link that can be forwarded. If the chat has already been shared, turn off the link and consider what copies may have been made by viewers.

## Safety and Limitations

The safest approach is to avoid putting information in a chat that you would not want exposed if someone gained access to your account. Use a password manager for credentials, not a conversation. Remove account numbers, passwords, private keys, and unnecessary personal information before asking an AI assistant to work with a document.

For a personal device, keep the operating-system account protected and use the device's screen lock. For a work account, follow your organization's data and retention policy. If you need a conversation to be unavailable to colleagues, check the Team or Enterprise sharing and export rules rather than assuming the same controls apply as on an individual plan.

Anthropic's help pages can change as new privacy and memory features roll out. The guidance here reflects the public pages reviewed on November 10, 2026. ## FAQ

**Can I lock one Claude chat with a PIN?**  
Anthropic's current public documentation does not describe a per-chat PIN or password. Protect access to your device and account instead.

**Is an Incognito Chat invisible to everyone?**  
No. It is not saved to normal chat history or memory, but Anthropic says it can be retained for safety. Team and Enterprise accounts may also include it in data exports.

**Can I use Incognito Chat inside a Project?**  
Anthropic's current help page says Incognito Chat is available outside Projects. For a chat inside a Project, you can use the per-chat Memory control instead.

**Will turning off memory delete my old chats?**  
No. It controls memory behavior. Your existing conversations remain in history unless you delete them separately.

**Can someone open a Claude chat if I send a link?**  
Anyone who has a public share link can open its snapshot. Turn off sharing when it is no longer needed, and do not share sensitive conversations publicly.

**Does deleting a chat remove its memory entry?**  
Not always. Anthropic's memory guidance says memory entries can remain after a conversation is deleted. Review the memory settings and remove any information you do not want retained.
